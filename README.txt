COVERNEO WEBSITE
================

IMPORTANT:
Sabhi files ko SAME FOLDER mein rakhein.
index.html ko open karke website run karein.


==================================================
KIS FILE ME KYA EDIT KARNA HAI?
==================================================


1. products.js
================

PRODUCTS ki saari details yahan edit hongi.

Yahan aap change kar sakte hain:

- Product Name
- Product Price
- Product Description
- Product Category
- Product Badge
- Product Search Name

Example:

name: "NeoShield Clear Case",
price: 699,
description: "iPhone 15 / 15 Pro",

Agar aapko:

Product ka naam change karna hai
Product ki price change karni hai
Product description change karni hai
New product add karna hai
Product remove karna hai
Badge change karna hai

TOH:

products.js EDIT KAREIN.


--------------------------------------------------

2. site.js
================

COMPANY aur CONTACT DETAILS yahan edit hongi.

Yahan aap change kar sakte hain:

- Company Name
- Logo Filename
- Phone Number
- WhatsApp Number
- Email
- Address
- Website Tagline

Example:

name: "CoverNeo",

logo: "coverneo-logo.png",

phone: "+91 9319990227",

whatsapp: "919319990227",

email: "support.coverneo@gmail.com",

address: "Our Store Address, Gurugram, Haryana",

tagline: "Premium accessories. Thoughtfully designed for your everyday."


Agar WhatsApp number change karna hai:
=> site.js

Agar Phone Number change karna hai:
=> site.js

Agar Email change karna hai:
=> site.js

Agar Address change karna hai:
=> site.js

Agar Company Tagline change karni hai:
=> site.js


--------------------------------------------------

3. coverneo-logo.png
================

Ye website ka LOGO hai.

Logo change karna ho toh:

1. New logo same folder mein rakhein.
2. Best option:
   New logo ka filename "coverneo-logo.png" rakhein.

Agar filename change karte hain,
toh site.js mein bhi:

logo: "new-logo.png"

karna hoga.


--------------------------------------------------

4. style.css
================

Website ka DESIGN yahan edit hoga.

Yahan aap change kar sakte hain:

- Website Colors
- Font Size
- Font
- Spacing
- Padding
- Margin
- Button Design
- Navbar Design
- Hero Section
- Product Cards
- Category Cards
- Footer

- Desktop Design
- Hover Effects

Agar website ka LOOK change karna hai:

--------------------------------------------------

5. index.html
================

Homepage ka MAIN STRUCTURE yahan hai.

Yahan aap change kar sakte hain:

- Homepage Heading
- Homepage Paragraph
- Navbar Text
- Buttons
- Device Section
- Categories Section
- Services Section
- About Section
- Why CoverNeo Section
- Newsletter Section
- Footer Structure
- HTML Content

IMPORTANT:

Products ki normal details ke liye
index.html ko edit na karein.

Products ke liye:

=> products.js


--------------------------------------------------

6. script.js
================

Website ki FUNCTIONALITY yahan hai.

Yahan mainly ye functions hain:

- Search
- Product Search
- Product Filter
- Add to Bag
- Cart
- Cart Quantity
- Cart Total
- Checkout
- WhatsApp Order
- Mobile Menu
- Search Overlay
- Cart Drawer
- Toast Message
- Category Click
- Other Website Interactions

IMPORTANT:

Sirf product name ya price change karne ke liye
script.js ko edit NA karein.

Uske liye:

=> products.js
